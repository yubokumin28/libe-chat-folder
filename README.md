# リベ チャット フォルダー

リベシティの「参加チャット」一覧をフォルダー分け・並び替えし、フォルダーごとの通知の合計を出す、Tampermonkey 用のユーザースクリプトです。
選んだ文字から日時を拾って、Googleカレンダーの予定作成画面を開くこともできます。

- 使い方と入れ方: https://yubokumin28.github.io/libe-chat-folder/
- インストール(Tampermonkey が必要): https://raw.githubusercontent.com/yubokumin28/libe-chat-folder/main/libe-chat-folder.user.js

保存はすべて利用者のブラウザの中(Tampermonkey とリベシティのページ側の控え)だけで、外へ送るものはありません。
リベシティ公式のツールではありません。
